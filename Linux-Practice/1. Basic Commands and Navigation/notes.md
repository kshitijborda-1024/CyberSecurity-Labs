# Linux Commands Learning Notes
## Objective
Practice Linux file management, navigation, and process monitoring.

# Commands Learned
## 1. pwd
- Used to display the current working directory.

## 2. cd
- Used to change directories.

## 3. mkdir
- Used to create directories.

## 4. touch
- Used to create empty files.

## 5. ls -a
- Used to list all files including hidden files.

## 6. cat
- Used to display file contents.

## 7. wc:
- lines
- words
- characters

## 8. cp
- Used to copy files.

## 9. mv
- Used to rename files.

## 10. top
- Used to display top running processes in system.
