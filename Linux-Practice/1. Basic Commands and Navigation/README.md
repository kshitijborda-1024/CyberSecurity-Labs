# Linux Commands & Navigation Practice

## Overview
This project contains hands-on Linux command-line practice focused on file management, directory navigation, searching, and process monitoring.

## Objectives
- Practice Linux terminal commands
- Understand file and directory operations
- Use search and process management commands

## Topics Covered
### File & Directory Navigation
- Creating directories
- Navigating folders
- Creating files
- Listing contents

### File Operations
- Reading files
- Counting lines, words, and characters
- Copying and renaming files

### Process & System Monitoring
- Viewing running processes

## Commands Practiced
- cd
- cd ~
- mkdir
- touch
- ls
- ls -a
- cat
- echo
- vim
- wc
- cp
- mv
- top

## Tools Used
- Kali Linux
- Linux Terminal
