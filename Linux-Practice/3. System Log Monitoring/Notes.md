# Linux System Log Monitoring Notes

## Objective
Learn how Linux system logs help monitor system activity, troubleshooting, and security events.

# Commands Learned
## journal
Used to view systemd logs.

## tail 
Used to monitor logs from bottom level.

## grep
Used to search logs for keywords.

# What I Learned
- Linux stores system activity in log files
- Authentication logs are important for security monitoring
- Logs help identify errors and suspicious activity

# Challenges Faced
- Understanding large log outputs
- Identifying useful information from logs

# Conclusion
This practical improved understanding of Linux monitoring and system log analysis.
