# Linux System Log Monitoring Report

## 1. Objective
The objective of this practical was to monitor Linux system logs, analyze authentication and system activity logs, and understand basic troubleshooting and monitoring techniques used in Linux environments.

# 2. Environment Used
| Component | Details |
|---|---|
| Operating System | Kali Linux |
| Platform | VirtualBox |
| Shell | Bash Terminal |
| Log Files Used | syslog, auth.log |

# 3. Introduction
Linux systems maintain log files that record system events, authentication attempts, kernel messages, and application activities. Monitoring logs is important for troubleshooting, security monitoring, and system administration.

# 4. Practical Tasks Performed
## 4.1 Viewing System Logs Using journalctl
### Command Used
sudo journal
### Description
The journal command was used to display systemd logs and monitor system events generated by services and the operating system.

## 4.2 Monitoring Logs in Real Time
### Command Used
sudo tail -f /var/log/syslog
### Description
The `tail -f` command was used to monitor the syslog file in real time and observe system activity as new log entries were generated.

## 4.3 Monitoring Authentication Logs
### Command Used
sudo cat /var/log/term.log
### Description
The `auth.log` file was analyzed to observe login attempts, authentication events, and sudo activity.

## 4.4 Searching Logs for Errors
### Command Used
sudo grep "error" 
### Description
The `grep` command was used to search for error-related entries inside the system log file.

# 5. Commands Summary
| Command | Purpose |
|---|---|
| journal | View system logs |
| tail | Monitor logs in bottom level |
| cat | Display log contents |
| grep | Search text inside logs |

# 6. Learning Outcome
This practical improved understanding of Linux log monitoring, authentication logs, kernel messages, and troubleshooting techniques used in system administration and cyber security.

# 7. Conclusion
The practical successfully demonstrated how Linux logs can be monitored and analyzed for troubleshooting and security purposes. This activity improved Linux administration and monitoring skills important in cyber security environments.
