# Linux System Log Monitoring

## Overview
This project demonstrates Linux system log monitoring and basic log analysis techniques using Kali Linux.

## Topics Covered
- System logs
- Authentication logs
- Real-time monitoring
- Kernel logs
- Error searching

## Commands Practiced
- journalctl
- tail
- head
- wc
- journal
- grep
- cat

## Tools Used
- Kali Linux
- Linux Terminal

## Learning Outcome
Improved understanding of Linux monitoring and troubleshooting concepts used in cyber security and system administration.
