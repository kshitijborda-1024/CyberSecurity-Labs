# Terminal Basics
## $
Represents regular user.
## #
Represents root user.
## sudo
Used to execute administrative/root commands.
## ctrl + c
Used to stop running commands.
## exit
Used to exit terminal.

# File & Directory Navigation
## pwd
Displays current working directory.
## ls
Lists files and directories.
## cd
Changes directory.
## cd ..
Moves to previous directory.
## cd ~
Moves to home directory.
## mkdir

## rmdir
Deletes empty directory.
## rm -rf
Deletes non-empty directory.
## touch
Creates empty file.
## rm

## mv

## cp

# File Permissions & Listing
## ls -R
Lists files recursively.
## ls -l
Displays permissions and details.
Permissions:
- r = read
- w = write
- x = execute
Permission groups:
- user
- group
- others
## ls -la
Displays hidden files with permissions.
## chmod
Changes file permissions.
## ls -a
Displays hidden files.
## Hidden Files
Files starting with "." are hidden.
