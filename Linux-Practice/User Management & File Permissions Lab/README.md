Linux User Management & File Permissions Lab

Overview:
This project demonstrates Linux user management and file permission handling in Kali Linux.

## Objectives
- Create Linux users
- Create and manage groups
- Configure file permissions
- Understand access control
- Practice Linux administration basics

## Tools Used
- Kali Linux
- Linux Terminal

## Practical Tasks
- Created users using adduser
- Created groups using groupadd
- Added users to groups
- Configured file ownership
- Applied Linux permissions

## Commands Used
- adduser
- groupadd
- usermod
- chmod
- ls -l

## Learning Outcome
This lab improved understanding of Linux security, user management, and file permission concepts.
