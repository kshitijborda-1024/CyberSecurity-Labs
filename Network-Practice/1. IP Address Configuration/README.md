# IP Address Configuration Lab

## Overview

This project demonstrates static and dynamic IP address configuration in Linux and Windows systems.

## Topics Covered

- Static IP configuration
- Dynamic IP configuration (DHCP)
- Network troubleshooting
- Connectivity testing

## Commands Practiced

- ifconfig
- dhclient
- ipconfig
- ping
- trace

## Tools Used

- Kali Linux
- Windows
- VirtualBox

## Learning Outcome

Improved understanding of networking fundamentals and IP address configuration techniques.
